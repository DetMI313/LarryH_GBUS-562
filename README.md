## About

This repository contains coursework, projects, and assignments completed for GBUS 562.

## Weekly Work

1. Week 1: An AI-coded Connect 4 game built with Claude Code.
2. Week 2: Prompt Lab, a single-page chat app (`week-02/prompt-lab.html`) that sends prompts to Claude (`claude-sonnet-5`) with an optional system prompt and exports each conversation as Markdown. Saved runs go in `week-02/runs/`.
3. Week 3: A document Q&A tool (`week-03/ask.py`) that uses retrieval-augmented generation (RAG). It indexes a document folder in its own Chroma database, retrieves the most relevant chunks, and has Claude (`claude-sonnet-5`) answer only from them. Use `--docs` to pick the folder (default `week-03/copperline-docs`) and `--save` to write a run to a file. Saved runs go in `week-03/runs/`, and the writeup is `week-03/writeup.md`.
